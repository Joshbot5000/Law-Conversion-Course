# Notes

One folder per module. Each chapter gets one Markdown (`.md`) file, written in the same shape every time so revision feels familiar:

**term → plain-English (ELI5) explanation → the cases that belong to it → a worked example**

Start a new chapter by copying [`templates/chapter-notes.md`](../templates/chapter-notes.md).
