# Templates

Copy a template, fill it in, and commit. Every time tutor feedback changes how you'd answer, **edit the template itself** and write what changed in the commit message (e.g. "Added contributory negligence step after tutor feedback on mock 2"). The History button on each file then shows exactly how your technique has improved over the term.

| Template | Use it for |
|---|---|
| [chapter-notes.md](chapter-notes.md) | New chapter notes: term → ELI5 → cases → worked example |
| [case-note.md](case-note.md) | One important case in depth |
| [pq-negligence.md](pq-negligence.md) | Tort negligence problem questions |
| [pq-criminal-homicide.md](pq-criminal-homicide.md) | Murder, partial defences, involuntary manslaughter |
| [pq-contract.md](pq-contract.md) | Formation and breach/remedies problem questions |
